# Локальный голосовой ввод в терминалах

В терминале откройте **скрепку → Голосовой ввод**. Можно записать голос с
телефона или компьютера либо выбрать готовый аудиофайл. Распознавание
выполняется на выбранном компьютере. Готовый текст можно поправить и
добавить в существующий черновик; отправка агенту остаётся отдельным действием.

## Подключение компьютера

Подготовленный модуль из проекта `local transcribve` — Windows-приложение.
Скопируйте на выбранный компьютер **всю папку «Панель агента»**, включая
`AgentDeskBridge.exe` и `_internal`. Python для готовой сборки не нужен.

Откройте **Настройки → Локальные возможности** на выбранном компьютере.
Скачайте модуль для Windows, распакуйте архив на этом компьютере и выберите
папку **«Панель агента» → Подключить**. Можно указать полный путь к
`AgentDeskBridge.exe`. Готовый архив модуля 1.0.0 занимает около 1,27 ГБ;
папка после распаковки — около 2,1 ГБ. Модели скачиваются отдельно.

В разделе доступны каталог моделей, **Установить модель / Использовать**,
язык и словарь замен. Каталог и ограничения CPU/GPU приходят из модуля,
включая Large v3 Turbo, Whisper, GigaAM, Parakeet и Qwen ASR. Установка
модели и её движка продолжается после выхода из настроек; возвращение
показывает ту же задачу. **Отменить** прекращает её. На установку отведено
до 30 минут; уже скачанные модели AgentDesk используются повторно.

**Проверить запись** показывает редактируемый результат в настройках и
не отправляет текст в терминал. Для обновления модуля распакуйте новую
сборку в другую папку и подключите её; модели остаются в прежнем кеше.
Старый модуль можно использовать для распознавания, но управление моделями
требует новой сборки. Сам запрос распознавания не скачивает модель из сети.

Отдельный сервер, порт, Telegram-бот и ключ облачного распознавания не нужны.
Интерфейс и агент выбранного компьютера должны содержать эту интеграцию.
На старом агенте новые API отсутствуют; обновите Remotai вместе с клиентом.

## Запись и отмена

Запись ограничена двумя минутами; готовый файл — 25 МБ. Длинная запись
останавливается и отправляется на распознавание автоматически по лимиту.
При отказе в доступе к микрофону можно разрешить его в настройках приложения
или браузера либо выбрать готовый файл. Запись в браузере требует доступного
микрофона и безопасного контекста; для веб-входа используйте HTTPS.

Распознавание идёт отдельной задачей, поэтому длительный вызов Whisper не
удерживает запрос через релей. **Отменить**, закрытие окна и переход к другому
терминалу прекращают задачу; поздний ответ не переносится в другой черновик.
На одном компьютере одновременно выполняется одна задача распознавания.
Новый модуль освобождает веса модели после каждой записи. Общий рабочий
процесс завершается после пяти минут простоя. При отмене завершается
его дерево процессов, включая дочерний FFmpeg.

## Для поддержки и разработки

Подключённый путь хранится отдельно от секретов Remotai, в
`%LOCALAPPDATA%/Remotai/transcription/connection.json`; локальная история
модуля — в `transcription/users/<UID>`. У разных серверных UID разные истории.
Телефон не получает прямой доступ к stdio-мосту. Запись загружается прежним
механизмом Remotai, и распознавать можно только завершённую загрузку того же UID.

Путь можно задать при запуске агента через `REMOTAI_AGENTDESK_EXE`. Без сохранённого
пути на Windows также проверяются модуль рядом с Remotai, папка
`%LOCALAPPDATA%/Remotai/transcription` и `%LOCALAPPDATA%/AgentDesk`.

Из подготовленного проекта использованы Go-клиент и адаптер записи; клиент
адаптирован к скрытому запуску и завершению дерева процессов Remotai.
Снимки компьютера по-прежнему доступны под скрепкой прежним действием.
OCR и отдельный интерфейс истории задач этой работой не подключались.

Сборка модуля из отдельного проекта: `pwsh -File scripts/build-agentdesk-module.ps1 -SourceProject <папка AgentDesk> -ModuleVersion 1.0.0`.
Исходники AgentDesk замораживаются в отдельном каталоге сборки. Remotai
добавляет только управление через stdio, используя исходные загрузчик,
движки, CUDA и FFmpeg; исходный проект не изменяется.
