# Самостоятельное развёртывание Remotai

[English](self-hosting.en.md) · **Русский**

Remotai можно развернуть на своей инфраструктуре без подписки на наш сервис.
Полный доступ включает терминалы, ИИ-агентов, серверные инструменты и управление
устройствами через собственный релей. Вы оплачиваете свой сервер и выбранные
ИИ-сервисы напрямую их провайдерам.

Приложение поддерживает русский и английский. Язык выбирается на экране входа
или в «Настройки → Помощь и конфиденциальность» и сохраняется на устройстве.
Имена ваших файлов и проектов, ввод и вывод терминалов не переводятся.
Для командной строки и меню Windows можно задать `REMOTAI_LANGUAGE=ru` или
`REMOTAI_LANGUAGE=en`; по умолчанию используется язык операционной системы.

Если вы предпочитаете готовый сервис с обслуживанием, используйте
[официальный Remotai](https://remotai.ru). Его облако работает по подписке.

## Что понадобится

- Linux-сервер с Docker Engine и Docker Compose v2.
- Домен, A/AAAA-записи которого указывают на этот сервер.
- Доступные входящие порты 80 и 443.
- Node.js 22 или новее для создания локальной конфигурации. Сборка приложения
  и релея выполняется внутри Docker.

Для первого запуска Telegram-бот, SMTP, OAuth и платёжный провайдер не нужны.
Можно подключить компьютер кодом и сохранить аккаунт в браузере. Для входа
в один аккаунт с нескольких браузеров настройте собственный Telegram-бот
или SMTP. Сохраните текущую браузерную сессию до настройки постоянного входа.

## Запуск на сервере

Из корня исходного кода выполните, подставив свой домен:

```bash
node scripts/init-self-hosted.mjs https://remotai.example.com
docker compose --env-file deploy/self-hosted/.env -f deploy/self-hosted/compose.yaml up -d --build
```

Откройте `https://remotai.example.com/app/`. Caddy выпускает TLS-сертификат
автоматически. Релей доступен контейнерам по внутренней сети; наружу открыт
только Caddy. Проверка состояния: `https://remotai.example.com/health`.

Инициализатор создаёт уникальный секрет подписи токенов, хранит его в
`deploy/self-hosted/.env` и не печатает значение. Повторный запуск не перезаписывает
файл. Сохраните его вместе с резервной копией: замена секрета завершает старые
сессии. Этот файл не должен попадать в Git или публичные архивы.

Настройка `SELF_HOSTED=true` задаётся оператором релея. В этом режиме подписка
Remotai не требуется, пробный период не расходуется, лимит тарифа на количество
устройств отсутствует. Авторизация, права на устройства и роли участников
продолжают проверяться. Одновременное включение `BILLING_ENABLED` запрещено.
При обычном запуске релея `SELF_HOSTED` по умолчанию выключен.

## Локальная проба

Для проверки на своём компьютере вместо публичного домена можно использовать:

```bash
node scripts/init-self-hosted.mjs http://localhost:18086
docker compose --env-file deploy/self-hosted/.env -f deploy/self-hosted/compose.yaml up -d --build
```

Откройте `http://localhost:18086/app/`. Порты привязаны только к loopback.
Такой адрес доступен браузеру на этом компьютере, а не телефону. Для телефона
используйте публичный домен с HTTPS. Для смены адреса отредактируйте `PUBLIC_URL`,
`SITE_ADDRESS` и порты в `.env`, затем пересоберите web-контейнер.

## Подключение компьютера или VPS

Соберите агент из этого же кода, как описано в `README.md`. На новой машине:

```bash
remotai install --no-pair
remotai pair --relay https://remotai.example.com
```

В Windows используйте `remotai.exe pair --relay https://remotai.example.com`.
На телефоне откройте свой `/app/`, выберите ввод кода и подтвердите код,
выданный агентом. Web-сборка уже настроена на ваш релей; при использовании
официального приложения укажите адрес в поле «свой сервер» на экране входа.
Привязку выполняйте под тем же системным пользователем, который запускает агент.

При самостоятельном размещении используйте собственные сборки агента.
Команда `scripts/build-self-hosted.mjs` помечает сборку версией `self-hosted`:
официальный механизм обновлений не заменяет такие сборки. Дополнительно можно
задать `"disable_auto_update": true` в конфигурации агента, чтобы отключить
фоновые обращения к манифесту официальных обновлений. Команда сборки не
запускает агент и не устанавливает его в автозагрузку.

## Дополнительные способы входа

Для Telegram задайте свои `BOT_TOKEN` и `BOT_USERNAME` в `.env`.
Токен получите у BotFather; служебные боты официального Remotai не используются.
В этом наборе размещается web-клиент `/app/`; Telegram Mini App потребует отдельной
сборки с `VITE_BASE=/tg/` и настройки адреса у BotFather.

Для email заполните `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASS`, `SMTP_FROM`.
После изменения конфигурации пересоздайте контейнеры той же командой Compose.

## Обновление и резервные копии

Данные аккаунтов и привязок находятся в томе `relay_data`; сертификаты — в
`caddy_data`. Делайте резервные копии базы и `.env` перед обновлением. Для снимка
базы остановите контейнер relay, скопируйте данные тома и запустите его снова.
Не удаляйте тома при обычном обновлении.

```bash
docker compose --env-file deploy/self-hosted/.env -f deploy/self-hosted/compose.yaml ps
docker compose --env-file deploy/self-hosted/.env -f deploy/self-hosted/compose.yaml logs --tail=100 relay
docker compose --env-file deploy/self-hosted/.env -f deploy/self-hosted/compose.yaml down
```

Последняя команда останавливает контейнеры и сохраняет тома. Флаг `--volumes`
удаляет данные и не используется для обычной остановки.

Удалённый экран работает через WebSocket без обязательного TURN. При необходимости
WebRTC через сложный NAT настройте свой TURN и его сетевые порты отдельно.
