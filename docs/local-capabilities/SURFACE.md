# Settings → Local capabilities

Режим: **Operate**. Область: `/settings?section=local` и `apk/src/transcription/LocalCapabilitiesSection.tsx`. Это расширение Settings; [DESIGN.md](DESIGN.md) описывает фактически использованные визуальные правила.

## Direction contract

**THESIS:** Управление распознаванием на выбранном компьютере через последовательные секции существующих настроек.

**OWN-WORLD:** Действующие `--tg-*`, общая типографика, кнопки и навигация Settings; тонкие разделители, открытые строки моделей, цели нажатия 44px.

**STORY:** Человек проверяет модуль, выбирает или устанавливает модель, сохраняет параметры и проверяет запись.

**FIRST VIEWPORT:** Общая шапка, имя компьютера, пояснение места обработки, статус и версия модуля; затем динамический каталог; ниже параметры и проверка.

**FORM:** Последовательное расширение Settings. Новая визуальная форма и seed не вводились; на мобильном экране строки моделей складываются.

**FINISH:** unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## Interaction contract

- Выход прекращает наблюдение за установкой, но сохраняет задачу на компьютере. При возвращении используется ID активной задачи; повторная установка вместо её продолжения не запускается. Только явная отмена адресует этот ID.
- Смена компьютера обновляет API и очищает локальные сведения и результат проверки. Поздний ответ старого компьютера не должен подменять текущий раздел.
- Готовая модель выбирается; отсутствующая модель или движок устанавливается. Активная готовая модель показана текстовым статусом. Во время задачи управляющие действия отключены.
- Язык и словарь сохраняются отдельно явной кнопкой. English отключён для модели только с русским языком; словарь остаётся раскрывающейся дополнительной настройкой.
- Проверка открывает общую шторку записи. Подтверждённый текст возвращается в результат внутри Settings через `onInsert={setTestText}`. Проверка не отправляет текст в PTY.

## Finish evidence

Ревью завершено без материальных дефектов интерфейса; исправление продолжения задачи после выхода принято. Снимки: `.impeccable/review/local/mobile.png` и `desktop.png`. Отдельные растровые материалы в поставку не добавлены.

Размер рекомендации (12px) и литерал резервного цвета ошибки остаются наблюдениями реализации, а не правилами нового визуального языка. Корневые DESIGN.md и sidecar не меняются: документация ограничена этим разделом.
