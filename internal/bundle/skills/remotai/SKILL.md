# Remotai на этом компьютере

Remotai — приложение владельца: через него он с телефона открывает терминалы
этой машины, смотрит файлы, экран и запускает агентов (тебя в том числе).
Ты можешь посмотреть и изменить его настройки прямо отсюда, командами.

Ничего настраивать заранее не нужно: команды ходят на локальный агент этой же
машины, без интернета и токенов.

## Сначала — состояние, потом настройки

```
remotai doctor
```

Печатает, что не так и чем лечится: приложение не запущено, компьютер не
привязан к аккаунту, выключен автозапуск, устарела версия, в аккаунт нейросети
не вошли, кончается лимит. Половина просьб «настрой тут всё» на самом деле про
это, а не про настройки.

Машиночитаемо — `remotai doctor --json`.

## Настройки

```
remotai config list            # что есть: ключ, значение, что означает
remotai config list --json     # то же для разбора
remotai config get <ключ>
remotai config set <ключ> <значение>
```

**Список настроек не заучивай — спроси его командой.** Он приходит с самого
приложения вместе с описаниями и допустимыми значениями, поэтому всегда
актуален; заученный список устареет после ближайшего обновления.

Пример:

```
remotai config set default_agent codex
remotai config set notifications_enabled false
```

## Что тебе менять нельзя

У части настроек в выводе стоит `[только владелец]`: порт, автозапуск,
привязка к облаку. Они могут отрезать человека от компьютера — а он в этот
момент смотрит в телефон, а не в терминал.

Если такая настройка действительно нужна:

```
remotai config set autostart true --reason "после перезагрузки компьютер пропадал из приложения"
```

Команда отправит владельцу просьбу и подождёт ответа (до 10 минут). Он
подтверждает в приложении. **Всегда пиши `--reason`** — человек решает по
причине, а не по имени ключа. Отклонили — не повторяй просьбу и не ищи обходной
путь: это его компьютер и его решение.

## Аккаунты нейросетей и лимиты

У владельца может быть несколько подписок на один сервис (например, две
Claude). `remotai doctor` покажет остаток по каждому и скажет, если в аккаунт
не вошли. Переключение — в приложении, раздел «Агенты»: там же аккаунт
закрепляется за папкой проекта.

Если упёрся в лимит — не молчи и не повторяй запрос по кругу: скажи об этом в
чате, а при необходимости напиши владельцу через скилл `telegram`.

## Правила

- **Меняй только то, о чём попросили.** «Посмотрим настройки» — это посмотреть
  и рассказать, а не привести всё к своему вкусу.
- **Скажи, что изменил**, и одной строкой — как вернуть обратно.
- **Не трогай чужое**: файлы `~/.tgcontrol-*.json` — внутреннее хозяйство
  приложения, правь их только через команды выше.
- Сообщить владельцу результат или спросить решение можно скиллом `telegram`
  (`remotai send`) — он читает Telegram чаще, чем терминал.
