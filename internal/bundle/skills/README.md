# Встроенные скиллы Remotai

Каждая подпапка — готовый скилл для AI-агента (Codex, Claude Code, Kimi).

## Как «установить» агенту

Проще всего — прямо в чате с агентом:

> Прочитай скилл в `~/Remotai/skills/telegram/SKILL.md` и следуй ему.

Или скопируй туда, где агент ищет скиллы сам:

- Claude Code: `~/.claude/skills/`
- Универсально (агенты читают AGENTS.md): упомяни путь в AGENTS.md проекта.

## Список

- `remotai/` — настройка и диагностика самого Remotai (`remotai doctor`,
  `remotai config`). Скажите агенту «посмотри настройки Remotai» — он разберётся
  сам: список настроек с описаниями приходит из приложения, заучивать нечего.
- `telegram/` — отправка сообщений и файлов владельцу в Telegram
  (`remotai send`).

Файлы здесь обновляются вместе с Remotai: свои правки в этой папке не храни,
делай копию.
