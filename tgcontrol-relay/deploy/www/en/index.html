What is Remotai

Remotai - convenient remote access to your AI agents. Claude Code, Codex and other agents work on your computer or server, with your projects, files and familiar environment. You run tasks, read the result, and respond to agents from your phone or other PC.

Install Remotai on a machine with agents, add it to your account using a code or QR and open the terminals. The machine must remain turned on and connected to the network. Files, SSH and desktop are available nearby when needed for a task.

Everything for working with agents at a distance

01

Full-fledged terminal, like on a computer

From the phone, the same terminal opens as on the computer, and not a stripped-down chat: it’s the same session. Launch Claude Code, Codex, Kimi, Gemini, Aider and OpenCode, enter commands, scroll through the output, answer the agent’s questions, press Esc and Ctrl+C. Everything that can be done on a computer can be done on a phone. You can see who is working and who is waiting for your answer.

$ claude "fix the build"  # on your machine
02

Continue where you left off

If you started working with an agent on a computer, continue using your phone. Work on the computer is not interrupted: the agent remains in the same terminal, and from the phone you see the same screen. Sessions and history are saved when Remotai is restarted and auto-updated. Team remotai attach opens the same session in a regular terminal on a PC.

03

Check the result on the screen

Open your computer screen to check the agent's output or perform an action in a graphical application. A virtual browser is available on a server without graphics. Computer Screen supported on Windows and Linux with X11; Not yet available on Mac.

04

Work with agents on the server

Connect your Linux server to Remotai or open an SSH terminal. Launch agents in a server environment and return to their tasks from your phone. Unknown SSH host is confirmed by fingerprint.

05

Project files nearby

Find and download the result of the agent’s work, transfer the required file. Next is the load on the processor, memory and processes to understand what is happening on the machine.

06

Only your devices

Add a computer using a one-time code or QR. Then manage from the devices you're signed into. The code confirms access to the desired computer, and the list of connected machines is available in “My Computers”.

07

Updates itself

New versions arrive on their own: the application checks the cloud, downloads and softly restarts when you close the window. The terminals do not die in this case.

How to work with AI agents through Remotai

How to start working with AI agents from your phone?

Click "Get Started" and connect the computer or server where your agents are running. On your phone, log into your Remotai account, open the connected machine and the “Terminals” section. Start an agent or continue its session in Remotai: you can read the result, submit tasks and answer questions.

Where do agents work and what is needed to run them?

Agents work on your computer or server, with your files and environment. Remotai gives you remote access to them. The installation and accounts of the AI ​​agents themselves are configured separately. The machine with the agents must remain turned on and connected to the network.

How to control a computer from your phone via Remotai?

Click “Start”, select “Connect a computer” and install Remotai on the desired machine according to the instructions for its system. On your phone, log into your account and add a computer using the code or QR. Files and terminals are available on Windows, Mac and Linux. The connected computer's screen runs on Windows and Linux with X11; The Mac screen itself is not yet accessible.

Do you need public IP address or port forwarding?

No. The computer itself establishes an outgoing TLS connection with the cloud relay Remotai, so there is no need to configure a router, VPN or public IP address.

What devices does Remotai work on?

You can connect Windows 10/11, macOS 12+ (Apple Silicon and Intel) or Linux amd64/arm64. Files, terminals, SSH, monitoring, and AI agents are available on the Mac, but the Mac screen itself is not yet accessible. The Linux screen requires an X11 session; work with Wayland has not yet been tested. You can control another computer from a browser on any of these systems, from an iPhone/iPad, Android 7+ or via Telegram.

What AI agents are supported?

Remotai recognizes Claude Code, Codex, Kimi, Gemini, Aider and OpenCode in the PTY terminal, shows the agent status and allows you to answer confirmation requests from the phone.

Is it possible to connect to Linux servers via SSH?

Yes. Remotai has an SSH center with hosts from ssh config, SFTP, ProxyJump and port forwarding. The Remotai agent itself is also installed on Linux with one command.

What does Remotai store in the cloud?

The cloud stores account and linked device data, minimal product analytics events, and voluntarily sent support messages. The contents of terminals, commands, files, screen, clipboard and clicks are not saved as analytics. Details - in privacy policy.

How much does Remotai cost?

Local work on your computer is free forever. Servers, SSH/SFTP, port forwarding and cloud access - 900 RUR/month (Pro, 5 devices) or 1,990 RUR/month (Fleet, 25 devices); the first 7 days are free and without a card. VPS rental is paid separately.

Installers and other login methods

On a computer or server with agents

Download for Windows

[!] The installer is not yet digitally signed. Windows may show "Unknown Publisher". Check that the file was downloaded from remotai.ru; then “More details” → “Run anyway”. In Edge: “⋯” → “Save” → “Save Anyway.”

On Windows, open Remotai and select Connect This PC. Autorun will leave it available after logging into Windows. Portable version without installer.

The macOS and Linux installers include Remotai 2.74.2. For Hermes, after connecting your computer, update Remotai to 2.75.1: “Settings” → “Connection and updates” → “Update now”.

Download for macOS - Intel and Apple Silicon

Open the DMG, drag Remotai into Applications, then open the application. The interface will appear in the browser.

The package is not yet signed with an Apple Developer ID. If your Mac doesn't allow opening, this step-by-step guide shows you where to allow it in System Preferences.

Download .deb - Ubuntu, Debian, Mint Download .rpm - Fedora, openSUSE

Open the file in the application installer and click Install. Then open Remotai from the application menu: the interface will appear in the browser.

In Remotai, select “Connect this computer” → “Via the Internet” to receive the connection code. Autorun can be enabled in the PC Panel.
