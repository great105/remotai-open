Claude Code and Codex CLI

Claude Code runs on your computer. And you are anywhere.

Claude Code is a console AI agent from Anthropic: it lives on your machine and sees your files, keys and environment. Hence its main limitation - they closed the laptop, work stopped. Remotai gives him a remote control: the agent’s terminal in his phone or browser, with history and answers to his questions.

On your computer on your home network - free forever. Access via the Internet - 7 days without a card, then 900 ₽ for 30 days. A Claude or OpenAI subscription is purchased from them and is not included in this price.

What is it and what is needed

Honestly and straight away: Remotai does not replace Claude Code and does not give access to it. Your agent, your account, your computer - we’re talking about how to reach them outside of your workplace.

Computer or server

Windows, macOS or Linux, where the agent is located and the projects are located. The machine must remain turned on: the agent works on it, not on us.

Your agent account

Anthropic, OpenAI, Moonshot, Google - whoever. Remotai doesn't include their subscriptions and doesn't store your keys: they stay on your machine.

Phone or browser

Android, iPhone, iPad, any browser, Telegram. There is nothing to configure in the router: the computer communicates itself.

Why would someone who already has an agent need this?

Claude Code doesn't know how to wait for you at the monitor. Four situations from which the product grew.

He asks - but you are not there

The agent stops at the question “apply the edit?” and stands there for hours. From the phone you can see who is waiting for an answer, and you can answer with one button.

The task is for an hour, and you have to go

They set the task and left. The terminal lives on the computer: when we return, the story is in place, nothing is broken.

Projects on the machine, not in the cloud

The cloud agent works in someone else's sandbox without your files, keys, or running services. Yours works for you.

Several agents at once

Claude Code, Codex, Kimi, Gemini, Aider, opencode - each in its own folder. You can see who is working, who is waiting, who has finished.

What does it look like

Four steps, then you simply write to the agent in the terminal.

Install Remotai on a machine with an agent

One installer for Windows, macOS and Linux. Placed in a user profile, no administrator rights required.

Link it to your account

Code or QR directly from this machine. White IP, VPN and router settings are not needed - the connection is outgoing.

Open terminal from phone

Select the project and agent folder. If the CLI is not yet installed, the application will show the installation command and help you select an account.

Give the task and leave

The answer will come to the same terminal. A notification will tell you when the agent has finished or asked.

Questions to ask before installation

Is Remotai an access to Claude Code?

No. Claude Code you install and pay for yourself, from Anthropic. Remotai is a remote control for it: it shows the terminal of your computer and transmits there what you typed.

Do my files and keys go to you?

No. The agent runs on your machine, files and keys remain there. What you see on the terminal screen and what you type goes through the cloud. The contents of terminals, commands, file names and screen frames are not stored in analytics.

What if I don’t have my own server?

It is not needed: the agent can run on a regular computer as long as it is turned on. If you want around the clock and without your computer - there is server scenario.

Does it work from Russia?

Remotai - yes: it has nothing to do with your machine or the agent's network. The availability of Claude Code itself depends on the network of the machine where it is running; analysis - in the article "Claude Code and Codex from Russia".

What other agents are supported?

Any console: Codex CLI, Kimi, Gemini CLI, Aider, opencode, Grok. The application knows their installation commands and can keep multiple accounts for each.

What happens if the computer turns off?

The agent will stop with him - he works on this machine. After turning on, Remotai rises by itself, terminals with history return.
